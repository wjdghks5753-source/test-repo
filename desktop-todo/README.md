# 오늘 할 일 — 노션 연동 데스크톱 체크리스트

바탕화면에 상주하면서 **오늘 해야 할 일을 알림으로 띄우고, 체크하면 노션에 자동으로 기록**하는 Windows 앱입니다.

- 지정한 시각(기본 08:30 / 13:00 / 18:00)에 남은 할 일을 알림으로 띄웁니다.
- 마감 시각 10분 전에 개별 알림을 보냅니다.
- 창에서 바로 할 일을 추가하면 노션 DB에 페이지가 만들어집니다.
- **제목을 누르면 그 자리에서 수정**됩니다 — 제목·마감 날짜·시각·분류·메모 전부. 노션에 들어갈 일이 없습니다.
- 체크박스를 누르면 노션의 `완료` 체크와 `완료일시`가 함께 기록됩니다.
- 체크한 항목은 목록에서 스르륵 빠져나가 **완료 섹션으로 접힙니다.** 헤더를 누르면 펼쳐집니다.
- 상단에 **완료율(%)** 과 `완료 / 전체 · 남은 N건 · 지연 N건` 이 표시됩니다.
- 요일 반복 할 일(예: 월·수·금 07:30 논문 리딩)을 등록하면 매일 아침 자동으로 오늘 목록에 올라옵니다.
- 인터넷이 끊겨도 그대로 쓸 수 있고, 연결되면 밀린 변경을 순서대로 노션에 보냅니다.

연동 대상 데이터베이스: **세종스포츠 DB / 🙋🏼‍♂️ 강정환 - TASK**

## 1. 설치

### 준비물

[Node.js LTS](https://nodejs.org) 를 설치합니다. 설치 중 옵션은 기본값 그대로 두면 됩니다.

### 앱 빌드

명령 프롬프트(또는 PowerShell)에서:

```bat
cd desktop-todo
npm install
npm run dist
```

`dist\` 폴더에 두 개가 만들어집니다.

| 파일 | 설명 |
|---|---|
| `오늘 할 일 Setup 1.0.0.exe` | 설치 프로그램. **이쪽을 권장합니다.** |
| `오늘할일-portable-1.0.0.exe` | 설치 없이 실행하는 단일 파일 |

> **설치 버전을 권장하는 이유:** Windows 10/11의 토스트 알림은 시작 메뉴에 바로가기가 있는 앱에만
> 안정적으로 표시됩니다. 포터블 버전은 알림이 뜨지 않거나 앱 이름이 `electron.app.…` 으로 보일 수 있습니다.

### 그냥 실행만 할 때 (빌드 없이)

폴더 안의 **`오늘할일.cmd` 를 더블클릭**하세요. 스스로 자기 폴더로 이동한 뒤, 필요하면 `npm install`
까지 하고 앱을 띄웁니다. PowerShell 에서 경로를 잘못 잡아 엉뚱한 곳에 설치되는 사고를 막아줍니다.

직접 명령으로 하려면, **반드시 `package.json` 이 있는 폴더에서**:

```bat
npm start
```

> 창이 뜨지 않으면 이미 트레이에 실행 중인 것입니다. 단일 인스턴스로 동작하므로
> 두 번째 실행은 조용히 종료됩니다. 트레이 아이콘 우클릭 → 종료 후 다시 실행하세요.

## 2. 노션 연결

앱을 처음 실행하면 설정 창이 자동으로 열립니다. 두 단계가 필요합니다.

### (1) 통합 토큰 만들기

1. 노션 → 우측 상단 **설정** → **연결** → **내 연결 개발 또는 관리**
2. **새 API 통합** 만들기 (이름은 아무거나, 예: `데스크톱 할 일`)
3. 기능에서 **콘텐츠 읽기 / 콘텐츠 업데이트 / 콘텐츠 삽입** 을 켭니다
4. **Internal Integration Secret** 을 복사합니다 (`ntn_` 또는 `secret_` 로 시작)

### (2) 데이터베이스에 통합 연결하기

**이 단계를 빠뜨리면 토큰이 맞아도 계속 404가 납니다.**

1. 노션에서 `강정환 - TASK` 데이터베이스를 페이지로 엽니다
2. 우측 상단 **···** → **연결** → 방금 만든 통합을 선택

### (3) 앱에 입력

설정 창에 토큰을 붙여넣고 **연결 테스트** → `연결됨: "강정환 - TASK" · 속성 확인 완료` 가 나오면 **저장**.

토큰은 Windows DPAPI(`safeStorage`)로 암호화해 저장하므로, 설정 파일을 그대로 복사해가도
다른 Windows 계정에서는 풀리지 않습니다.

## 3. 사용하는 노션 속성

| 속성 | 타입 | 앱에서의 역할 |
|---|---|---|
| `할 일` | 제목 | 할 일 내용 |
| `완료` | 체크박스 | 체크 상태 |
| `마감일` | 날짜(시간 포함) | 오늘 목록에 올릴 기준, 마감 임박 알림 |
| `텍스트` | 텍스트 | 메모 (목록에 한 줄로 표시) |
| `완료일시` | 날짜 | **체크한 시각**을 앱이 자동 기록 |
| `분류` | 선택 | 스터디 / 업무 / 환자 / 연구 / 개인 |
| `출처` | 선택 | 앱 / 노션 / 루틴 — 어디서 만들어졌는지 |

뒤 세 개는 이 앱을 위해 추가한 속성입니다. **속성이 없어도 앱은 동작합니다** —
DB 스키마를 읽어 없는 속성은 건너뜁니다. 다만 `완료일시`가 없으면 "언제 끝냈는지" 기록이 남지 않아
누적 통계를 낼 수 없습니다.

속성 이름을 노션에서 바꿨다면 `src/main/notion.js` 상단의 `P` 객체만 고치면 됩니다.

## 4. 오늘 목록에 올라오는 기준

1. `완료`가 꺼져 있고 `마감일`이 **오늘이거나 지난** 항목 (기본 최근 7일치까지 — 설정의 *지난 미완료 끌어오기*)
2. `마감일`이 비어 있고 최근에 만들어진 항목 (설정에서 끌 수 있음)
3. 오늘 `완료일시`가 찍힌 항목 (완료 섹션에 표시)
4. 오늘 요일에 해당하는 반복 할 일

지연된 항목은 목록 맨 위 **지연** 섹션에 빨간 태그로 따로 모입니다.

### 항목 수정

**제목을 클릭**하거나 줄 오른쪽의 **✎** 버튼을 누르면 그 줄이 편집 폼으로 바뀝니다.

| 항목 | 설명 |
|---|---|
| 제목 | 내용 수정 |
| 날짜 | 비우면 마감일 없음이 됩니다 |
| 시각 | 비우면 종일 항목이 됩니다 |
| 분류 | 스터디 / 업무 / 환자 / 연구 / 개인 |
| 메모 | 노션 `텍스트` 속성 |
| **내일로** | 날짜를 하루 미룹니다 (누른 뒤 **저장**을 눌러야 반영) |

`Enter` 저장, `Esc` 취소. 저장하면 노션에도 곧바로 반영됩니다.
편집 중에는 자동 동기화가 화면을 다시 그리지 않으므로, 입력하던 내용이 중간에 날아가지 않습니다.

### 완료 항목과 완료율

체크한 항목은 기본적으로 **접힌 완료 섹션**으로 들어가 목록에서 보이지 않습니다.
밀린 일을 한꺼번에 정리한 날이면 완료 항목이 수십 개가 되어, 정작 남은 할 일이 그 아래로 파묻히기 때문입니다.
완료 섹션 안에서는 **가장 최근에 끝낸 것이 맨 위**에 옵니다.
항상 펼쳐두고 싶으면 설정 → 동기화 → *체크한 항목은 접어서 숨기기* 를 끄세요.

완료율은 **항목 개수 기준**입니다 — `완료 개수 ÷ 오늘 목록 전체 개수`.
**99% 이상이면 100%로 올려서 보여줍니다.** 거의 다 끝낸 날 99%에서 멈춰 있는 것보다 낫다는 판단이고,
정확한 숫자는 바로 아래 `79 / 80 완료 · 남은 1건` 이 항상 같이 알려줍니다.
막대와 숫자가 **초록색으로 바뀌는 건 진짜로 남은 항목이 0일 때뿐**이라, 100%(약식)와 완주는 색으로 구분됩니다.

> **주의:** 이 퍼센트는 "오늘 몫을 얼마나 했나"가 아니라 "지금 목록에서 몇 개를 체크했나"입니다.
> 몇 달 밀린 항목을 한꺼번에 정리하면 98% 같은 숫자가 나오는데, 그날의 실제 업무량과는 무관합니다.
> 분모가 되는 목록 범위는 아래 `carryOverDays` 설정이 결정합니다.

## 5. 알아둘 점 / 한계

- **동기화는 주기적입니다(기본 5분).** 노션에서 바로 고친 내용이 앱에 뜨기까지 최대 5분이 걸립니다.
  즉시 반영하려면 창의 ⟳ 버튼을 누르세요. 노션은 웹훅을 이 방식으로 제공하지 않아 실시간 반영은 안 됩니다.
- **충돌은 나중에 쓴 쪽이 이깁니다.** 같은 항목을 앱과 노션에서 동시에 고치면 나중 변경이 덮어씁니다.
  실무에서 부딪힐 일은 거의 없지만, 병합해주지는 않습니다.
- **여러 대에서 동시에 쓰면 반복 할 일이 중복 생성됩니다.** "오늘 몫을 만들었다"는 기록이
  각 PC에 따로 저장되기 때문입니다. 반복 할 일은 한 대에서만 켜두세요.
- **삭제는 노션 휴지통으로 갑니다.** 완전 삭제가 아니라 보관(archive) 처리입니다.
- 노션 API는 초당 약 3회 제한이 있어 앱이 호출을 한 줄로 세워 보냅니다. 항목이 수백 개면 첫 동기화가 몇 초 걸립니다.
- **`지난 미완료 끌어오기`를 0(전체)으로 두면** 몇 달 전 미완료 항목까지 전부 오늘 목록에 올라옵니다.
  한 번 정리할 때는 유용하지만, 평소에는 7~14일 정도로 두는 편이 목록을 읽을 수 있게 유지합니다.
- X 버튼은 종료가 아니라 **트레이로 숨기기**입니다. 완전히 끄려면 트레이 아이콘 우클릭 → 종료.

## 6. 문제가 생기면

| 증상 | 확인할 것 |
|---|---|
| `Could not find database with ID` | 2-(2) 단계, 즉 DB에 통합을 연결했는지 |
| `API token is invalid` | 토큰을 다시 복사 (앞뒤 공백 주의) |
| `프록시나 방화벽이…` | 회사망에서 `api.notion.com` 이 막혀 있는지 |
| 알림이 안 뜸 | Windows 설정 → 시스템 → 알림에서 **오늘 할 일** 허용, 집중 지원(방해 금지) 해제 |
| 창이 안 보임 | 트레이 아이콘 클릭. 모니터를 뺐다 꽂으면 위치가 초기화됩니다 |
| `EPERM ... C:\windows\package-lock.json` | 엉뚱한 폴더에서 `npm install` 을 한 것입니다. `오늘할일.cmd` 로 실행하세요 |
| 실행이 느리거나 파일이 잠김 | 아래 OneDrive 항목 참고 |

### OneDrive 폴더에 두지 마세요

이 폴더를 OneDrive 안에 두면 `node_modules` 의 수만 개 파일을 OneDrive 가 계속 동기화하려 듭니다.
설치가 느려지고, "파일 온디맨드"로 내용이 비어 있는 상태에서 앱이 실행에 실패할 수 있습니다.

`C:\Users\<사용자>\desktop-todo` 처럼 **동기화되지 않는 곳으로 폴더째 옮기는 것**을 권합니다.
설정과 노션 토큰은 `%APPDATA%\오늘 할 일\` 에 따로 있으므로 폴더를 옮겨도 그대로 유지됩니다.

설정과 캐시 위치: `%APPDATA%\오늘 할 일\` (`config.json`, `cache.json`, `routines.json`)
문제가 계속되면 이 폴더를 지우고 다시 실행하면 초기 상태로 돌아갑니다. 노션 데이터는 그대로입니다.

## 7. 개발자용

```bat
npm test          :: 노션 호출 없이 동기화/큐/루틴/완료율 로직 검증 (37개)
npm start         :: 개발 실행
npm run pack      :: 설치 파일 없이 폴더로만 빌드
```

| 파일 | 역할 |
|---|---|
| `오늘할일.cmd` | 윈도우용 실행 스크립트 (자기 폴더로 이동 후 npm start) |
| `src/main/main.js` | 창, 트레이, 알림, IPC |
| `src/main/notion.js` | 노션 REST 클라이언트 (외부 의존성 없음) |
| `src/main/sync.js` | 낙관적 갱신 + outbox 큐 |
| `src/main/scheduler.js` | 정시 알림, 날짜 넘김, 주기 동기화 |
| `src/main/routines.js` | 요일 반복 할 일 |
| `src/renderer/` | 화면 (Node 접근 차단, contextIsolation) |
| `src/renderer/util.js` | 완료율·마감일 계산 (화면과 테스트가 공유) |

런타임 의존성은 없습니다. `electron`과 `electron-builder`는 빌드용입니다.
